# 台湾地质钻孔数据批量下载工具

## 简介

这是一个自动化工具，用于批量下载台湾地质钻孔数据，包括基本资料、试验数据、柱状图和岩心照片。本工具特别适合需要处理大量钻孔数据的地质工作者、研究人员和工程师。

## 准备工作

在使用本工具前，您需要先安装以下软件：

1. **Node.js**（版本16或更高）
    - 访问 [Node.js官网](https://nodejs.org/)
    - 下载并安装适合您操作系统的版本
    - 安装时选择"默认设置"即可
2. **网络代理**（如果您在中国大陆使用）
    - 确保您有可用的网络代理
    - 默认代理设置为`http://127.0.0.1:7897`，如需修改请参考配置部分

## 安装步骤

1. **解压下载的zip文件**到您选择的文件夹

2. **打开命令提示符或终端**

    - Windows: 按`Win+R`，输入`cmd`，点击确定
    - Mac: 打开应用程序 > 实用工具 > 终端

3. **进入程序目录**

   ```
   cd 您解压文件的路径
   ```

   例如：`cd C:\Users\YourName\Downloads\drill_crawler`

4. **安装依赖**

   ```
   npm install
   ```

   这一步会自动安装程序运行所需的所有库

5. **安装浏览器驱动**

   ```
   npx playwright install chromium
   ```

   这会安装程序使用的浏览器引擎

## ⚙️ 配置说明

脚本中的 `CONFIG` 对象包含所有可调整的配置项：

| 配置项            | 说明                                 | 默认值                                          |
| ----------------- | ------------------------------------ | ----------------------------------------------- |
| outputDir         | 输出目录路径                         | ./drill_data                                    |
| browser.headless  | 是否使用无头模式（不显示浏览器窗口） | false                                           |
| browser.proxy     | 代理服务器设置                       | [http://127.0.0.1:7897](http://127.0.0.1:7897/) |
| searchArea        | 搜索区域（WKT格式多边形）            | POLYGON((12705872.421750566...))                |
| minDelay          | 最小延迟时间(ms)                     | 100                                             |
| maxDelay          | 最大延迟时间(ms)                     | 2000                                            |
| initialDelay      | 初始延迟时间(ms)                     | 500                                             |
| maxRetries        | 最大重试次数                         | 3                                               |
| workerCount       | 工作线程数                           | CPU核心数-1                                     |
| projectsPerWorker | 每个工作线程处理的项目数             | 50                                              |
| resumeable        | 是否支持断点续传                     | true                                            |
| saveBaseData      | 是否保存基本资料                     | true                                            |
| saveTestData      | 是否保存试验资料                     | true                                            |
| saveChartImages   | 是否保存柱状图                       | true                                            |
| saveCoreImages    | 是否保存岩心照片                     | true                                            |
| logLevel          | 日志级别                             | info                                            |

> 💡 **小贴士**：如果你不确定如何修改这些配置，保持默认值即可。如需修改，请用文本编辑器（如记事本、VS Code）打开 `drill_crawler.js` 文件，找到 `CONFIG` 部分进行修改。

## 🚀 基本使用方法

### 开始下载数据

在命令提示符或终端中运行：

```
npm start
```

程序会执行以下操作：

1. 获取所有钻探项目列表
2. 按批次处理项目（多线程并行）
3. 为每个项目下载钻孔数据（基本资料、试验数据、柱状图、岩心照片）
4. 保存处理状态，支持中断后继续处理

### 查看下载进度

程序会在运行过程中显示进度信息：

- 已完成项目数量和百分比
- 当前正在处理的批次
- 遇到的错误和警告

### 📂 输出文件结构

所有数据保存在`drill_data`目录下，按以下结构组织：

```
drill_data/
  ├── 项目名称1(钻孔数量)/
  │   └── details/
  │       ├── hole_钻孔编号1/
  │       │   ├── base_data.csv    - 基本资料
  │       │   ├── test_data.csv    - 试验数据
  │       │   ├── chart_data/      - 柱状图文件夹
  │       │   │   └── 柱状图_1_1.png
  │       │   └── core_data/       - 岩心照片文件夹
  │       │       └── 深度xx-xx公尺.jpg
  │       ├── hole_钻孔编号2/
  │       └── ...
  ├── 项目名称2(钻孔数量)/
  └── ...
```

## 高级功能

### 从日志导入已处理项目ID

如果您有之前运行的日志文件，可以从中提取已处理的项目ID，避免重复下载：

```
npm start -- --import-log 日志文件路径
```

例如：`npm start -- --import-log old_log.txt`

### 中断与继续

程序支持随时中断（按`Ctrl+C`）后继续处理：

1. 中断程序后，已处理的项目状态会自动保存
2. 再次运行程序时，会自动跳过已完成的项目
3. 处理状态保存在`drill_config/processing_status.json`中

## 常见问题解答

### Q: 程序运行时报错"Cannot find module..."

**解决方案**: 请确保您已在程序目录下运行了`npm install`命令。

### Q: 无法连接到地质数据网站

**解决方案**:

1. 检查您的网络连接
2. 确认代理设置是否正确
3. 网站可能暂时维护中，稍后再试

### Q: CSV文件在Excel中显示乱码

**解决方案**:

1. 在Excel中，使用"数据"→"从文本"导入
2. 选择"分隔符号"并设置编码为"简体中文(GB2312)"
3. 完成导入向导

### Q: 程序下载速度很慢

**解决方案**:

1. 减少`CONFIG.workerCount`值减轻网络负担
2. 增加`CONFIG.initialDelay`值减少请求频率
3. 检查网络状况和代理质量
